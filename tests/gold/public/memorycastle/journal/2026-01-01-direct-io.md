# Compaction reads use direct I/O
Author: fixture+claude | Date: 2026-01-14
Files: `src/compact.rs`

## Decision
Compaction opens input tables with O_DIRECT so it does not evict the page cache that serves reads.

## Rejected
- Buffered compaction reads: read hit rate fell from 91% to 60% during compaction.

## Measured
- Page cache hit rate during compaction stays at 89%.
